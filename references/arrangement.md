# 配器与风格设计

先列角色：主旋律、齐奏、和声内声、低音、节奏、反旋律、过门、纹理和效果。角色可由乐器接力。记录各实际段落的家族参与、音区、织体、奏法、能量和前后景；重复段不要求固定次数或机械递增，发展服从曲式与风格。

保存风格brief：目标/参考、必须保留的元素、乐器/音色家族、密度/动态走向、节奏语汇、空间/年代特征、混音目标及验收听点。`assets/style-profiles.json`是开放示例，可新建风格；不做固定分类器，不以1980s合成器预设代表所有风格。

| 目标 | 可调音乐变量 | 需要防止的问题 |
|---|---|---|
| 大型、丰满 | 独立内声/divisi、宽音区、家族合奏、实际并发与舞台 | 同patch同音复制、低中频拥挤、无功能填满 |
| 清亮、通透 | 旋律同度/八度支撑、开阔和弦、减少低中频重叠 | 高音长期过强、尖锐共振 |
| 厚重、有推动力 | 低弦/低铜管、节奏重音、低频音值分配 | 鼓吞旋律、所有低音乐器挤同一音区 |
| 现代交响 | 保持乐团主体，融合现代节奏/吉他/sax/电子纹理 | 缩成独奏伴奏而失去要求的规模 |
| 复古电子/蒸汽波 | 振荡器/失谐/FM/包络、电子织体、chorus/delay/gated空间 | 仅套效果、擅自变速改旋律、混淆子风格 |
| 民族/跨界 | 真实音域、惯用装饰、异质齐奏、呼吸/拨弦节奏 | 只换标签、假装拥有未采样奏法 |

## 和声与声部进行

对新增和声，从当前和弦实音pcs在乐器音域内生成候选，结合目标音区、前音移动、次序、间距、功能解决和重复采样占用选择。`scripts/voicing.py`提供确定性搜索，不负责决定风格或填满全曲。

密集爵士、开阔电影和声、复调、齐奏使用不同代价。非和弦伴奏音、挂留、经过线、再和声明确标记；不能为通过和弦内音检查删原旋律。低音按`bass_pc`单独核对，斜线低音可能不在三和弦pcs内。

避免全部声部长期平行移动，给低音、内声、反旋律不同节奏和连接任务。旋律需要空间，节奏需要可辨认的攻击。扩密度后测量并试听实际参与的家族，轨道存在不表示发挥作用。

## 演奏与能力

每部记录实音音域、polyphony、长短音/连奏、动态/颤音/亮度CC、keyswitch、trigger transpose、释放、延迟和round-robin。缺少采样滑音/连奏时不得声称是真实采样奏法。多音和弦不能直接送进会off_by抢音的单音patch。

名义音符不变，gate、微时序、力度、呼吸、弓法/拨弦重击和CC在独立层调整。humanization使用固定种子和有音乐依据的边界，不能随机破坏合奏攻击。八度、触发键、移调明确映射，不能通过改原曲基准掩盖。
