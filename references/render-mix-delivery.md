# 渲染、混音与交付

## 后端选择

原生采样/DAW适合真实乐器；DSP适合电子设计与无外部采样的可控试听。可以组合，但每部的backend、音源身份、preset、奏法与处理链必须可追溯。随附DSP固定48kHz，提供21种电子预设；可新增/调整预设并保存哈希。它不模拟所有真实乐器，不应给任何风格强行套同一音色。

先验证乐器：低/中/高音、短/长音、重复音、和弦、CC、release、采样音准、控制键与实音映射。对相同音高重叠和单音off_by尤其注意。CC1可能是动态、颤音或亮度；某些音源把channel-mode控制器当音色参数，需要私有适配并复测。历史案例中的CC重映射或特定采样修音不可普遍套用。

分轨统一采样率、声道、起点、frame count、释放尾音；长混响分配足够尾长。原始轨保持浮点，不以整数写入削掉中间峰值。后端中的默认reverb/EQ/pan也需记录或关闭，避免与混音重复叠加。

随附SFZ后端每部加载一个SFZ并发送note/CC，`articulation`文字不会自动变成keyswitch。可按奏法拆部/选独立SFZ；需要复杂keyswitch、连奏脚本或pitch bend时用保存了原生映射的外部后端。DSP的articulation只提供基础短音包络调整，不宣称真实弓法。

## 混音决策

先建立旋律/节奏可辨认的静态平衡，再用EQ/音区/奏法减少遮挡。低频厚度可由低弦、低铜管、低音合成器与鼓分工提供；同时持续低频越多越需控制音值。高音合奏结合音区、采样亮度与动态，避免长期尖锐。舞台声像、早期反射和混响建立规模，保留mono可用性。

家族预算与段落自动化保存为配置，读取实际打印轨测量。不要把每条稀疏轨都归一化为同一RMS。高潮增长依靠参与层、音区、和声和表达，不能只加总音量或鼓。

随附mixer是可复现的基础链：每部滤波/固定gain/声像/显式dB自动化 → 可选独立wet returns → 明确末尾fade → 线性premaster → 可选tape/固定master gain/全局峰值衰减。它没有高级动态EQ、侧链或通用母带限制器；有需要使用DAW/插件并保存状态。4x true-peak是估计，交付还看ffmpeg实测及最终编码结果；不能把PCM检查等同于MP3检查。

响度目标由风格、用途、参考与用户决定。A/B对齐整体响度及相同段落，保留段落动态。记录耳朵反馈来自谁、哪段、哪个版本；没有实际听过就不能写“听感验收通过”。

## MIDI与谱面

GM兼容MIDI和原生采样器MIDI分别标记。多端口/分组避免通道共享导致换音色，鼓通道与旋律分开。控制键不进音乐音符数量，Native滤波CC不盲目带到GM颤音。

总谱从名义音乐层生成：music21/MusicXML或DAW记谱器 → Verovio/其他已知排版器 → PDF/SVG。处理转调乐器与实音总谱标记、和弦分组、多voice、跨小节连线、重复音重击、双谱表和谱号。真实重叠不能为方便排版截短；表现gate/微时序不直接写成难读节奏。比较音高、名义起点和总时值，再渲染全页检查边界、拥挤、文字与可读性；遇到对应文档技能时按其渲染要求执行。

## 交付与封存

按任务交付完整试听及关键段预览、无损master、MIDI/原生映射、可编辑MusicXML/PDF、raw/processed stems及FX returns。明确哪组相加构成premaster、fade是否已包含、master是线性还是非线性。不能把family buses和组成它的individual stems再次相加。

保存源底稿/证据、风格brief、section plan、能力映射、预设/补丁、混音/母带、验证报告、依赖lock、环境/模型权重身份、命令及随机种子。采样库可按许可提供或给出固定来源+获取步骤+内容校验；不能遗漏后声称cold-start完整。保存原WAV哈希以核对原交付；重新编码的MP3/PDF/ZIP容器不要求字节一致。
